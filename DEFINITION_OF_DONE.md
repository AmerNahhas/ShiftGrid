# Definition of Done – ShiftGrid

**Project:** ShiftGrid – Workforce Scheduling App  
**Maintained by:** Amer Nahhas (Scrum Master)  
**Last updated:** June 2026

---

## Overview

The Definition of Done (DoD) is a shared agreement between the Scrum team that defines the minimum quality standards a work item must meet before it can be marked as Done. No story, bug, or feature is considered complete until all criteria below are satisfied.

---

## Story-Level Definition of Done

A user story is Done when:

- [ ] All acceptance criteria listed in the ticket are met
- [ ] Code reviewed by at least one team member
- [ ] Feature tested on both mobile (iOS Safari) and desktop (Chrome)
- [ ] No critical or high-severity bugs introduced
- [ ] In-app notifications tested and confirmed working where applicable
- [ ] Ticket updated with final comments and QA sign-off
- [ ] Story moved to Done on the Jira board by the Scrum Master

---

## Bug-Level Definition of Done

A bug ticket is Done when:

- [ ] Root cause identified and documented in the ticket
- [ ] Fix verified on the affected platform (device/browser)
- [ ] Regression test run — no new issues introduced
- [ ] Priya (QA) has signed off in the ticket comments
- [ ] Priority reassessed after fix — ticket updated accordingly

---

## Sprint-Level Definition of Done

A sprint is Done when:

- [ ] All committed stories meet the story-level DoD above
- [ ] Sprint goal achieved or deviation documented with reason
- [ ] Burndown chart reviewed by Scrum Master
- [ ] Sprint retrospective completed and action items recorded
- [ ] Unfinished items triaged — moved to next sprint or backlog with justification
- [ ] Stakeholder sprint review summary written and shared

---

## What Does NOT Count as Done

- A story where acceptance criteria are partially met
- A ticket moved to Done without QA sign-off
- A bug "fixed" but not tested on the affected device
- Any item completed without a comment trail in Jira

---

## Notes

This DoD was established at the start of Sprint 1 and applies to all sprints in the ShiftGrid project. Updates to the DoD are made during retrospectives with full team agreement.
